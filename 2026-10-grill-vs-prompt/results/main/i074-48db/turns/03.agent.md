The design is now fully settled: equality is an allowed support no-op, `ADMIN` takes precedence over `SUPPORT`, approver-only status adds nothing, and `accounts:write` is mandatory. I’m implementing the endpoint and focused tests now, then I’ll run the required offline Maven suite.

Implemented `PUT /api/accounts/{accountId}/daily-limit`.

Behavior includes:

- Admins can set any valid limit.
- Assigned support users can lower or leave unchanged, but cannot raise it.
- Customers and unauthorized roles are rejected.
- Closed accounts return `409`.
- Missing, negative, fractional, null, or out-of-range values return `400`.
- Successful responses use the existing account representation.
