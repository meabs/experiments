Implemented `PUT /api/accounts/{accountId}/daily-limit`.

Behavior includes:

- Requires `accounts:write`.
- Tenant admins may set limits up to £5,000.
- Assigned support may lower limits only; raising returns `403`.
- Customers and unauthorized staff cannot change limits.
- Closed accounts return `409`.
- Missing, negative, fractional, non-numeric, or over-£5,000 values return `400`.
- Successful updates return the normal account view.
- Every update records an internal account note containing the old and new limits and the acting user.
