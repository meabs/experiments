Implemented `POST /api/accounts/{accountId}/notes`.

- Staff/admin role plus `accounts:write` required.
- Enforces account visibility and tenant/assignment access.
- Trims and validates `body` to 1–2000 characters.
- Strictly accepts boolean `internal`.
- Saves caller ID and creation timestamp.
- Returns the requested 201 response shape.
- Missing/invisible accounts return 404; invalid input returns 400.

`mvn -o -q test` passes.
