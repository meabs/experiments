Ticket: approve closure requests.

Customers (or an admin, for them) ask for an account to be closed with `POST /api/accounts/{accountId}/closure-requests`,
and approvers see the pending requests with `GET /api/closure-requests`. Approvers now need to approve them.

Add `POST /api/closure-requests/{requestId}/approve`. The request's status becomes `APPROVED`, with `decidedBy` (the
caller) and `decidedAt` set, and the account's status becomes `CLOSED`. It returns the request in the same shape as
`GET /api/closure-requests`.
