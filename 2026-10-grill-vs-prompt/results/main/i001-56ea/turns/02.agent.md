Implemented `PUT /api/accounts/{accountId}/daily-limit`.

Behavior includes:

- Bank admins can set any non-negative whole-pound limit.
- Assigned support users can lower (or keep) the limit, but cannot raise it.
- Customers and unauthorized staff receive 403.
- Inaccessible accounts return 404.
- Closed accounts return 409.
- Missing, negative, fractional, null, or out-of-range values return 400.
- Successful responses use the existing account view shape.
