Implemented `PUT /api/support/cases/{caseId}/assignee`.

Behavior includes:

- Admins can reassign cases within their tenant.
- The current assignee may hand over their case.
- Other support users receive `404`.
- Requires `accounts:write`.
- New assignee must be assigned to the case’s account via `support_assignments`; invalid IDs return `400`.
- Only open cases can be reassigned.
- Returns the requested case fields.

Tests pass with `mvn -o -q test`.
