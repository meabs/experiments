The design tree is now settled:

- `POST /api/accounts/{accountId}/notes`
- Requires `accounts:write` and `SUPPORT` or `ADMIN`
- Reuses `getVisible`: assigned support accounts or same-tenant admin accounts; inaccessible/missing is 404
- Requires `body` and `internal`; strict boolean, trimmed body length 1–2000; saves trimmed text
- Stores caller `sub` as `author`, uses server `Instant.now()` for `createdAt`
- Returns 201 with exactly `id`, `author`, `body`, `internal`, `createdAt`
- Keeps normal handling for unknown JSON fields and existing error conventions

This is the shared understanding. I’m proceeding to implement and test it.
