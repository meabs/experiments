Ticket: reassign support cases.

Cases sometimes need to move to a different support user, for example when someone goes on leave. This is done in the back
office; customers can't.

Add `PUT /api/support/cases/{caseId}/assignee` with the body `{"assigneeUserId": "..."}`. It sets the case's assignee
and returns `{"id", "accountId", "subject", "status", "assigneeUserId", "openedAt"}`.

Follow the existing conventions (README.md) and keep the existing behaviour and tests working.

Use grill-with-docs on this before you build it.
