The design tree is now settled:

- `POST /api/accounts/{accountId}/notes`, protected by `accounts:write`.
- Only `SUPPORT` and `ADMIN` may create notes.
- Support must be assigned to the account; admins must share its tenant.
- Invisible/missing accounts return the existing 404; identifiable unauthorized support returns 403.
- `body` is trimmed first, then must be 1–2000 characters; the trimmed value is persisted.
- `internal` is required and must be a JSON boolean, including explicit `false`.
- Author comes from the current caller; `createdAt` is the current service timestamp.
- Closed accounts are not specially blocked.
- Success is 201 with exactly `id`, `author`, `body`, `internal`, and `createdAt`.
