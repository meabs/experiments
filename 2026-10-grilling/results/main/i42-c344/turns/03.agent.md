The design tree is now fully settled:

- `POST /api/accounts/{accountId}/notes`
- Requires authentication, `accounts:write`, and `SUPPORT` or `ADMIN`.
- Account visibility is checked first for resource masking: inaccessible/missing means 404.
- Support must be assigned to the account and may create only `internal: true`; `internal: false` is 403 with no save.
- Admins in the account’s tenant may create either kind.
- `body` and `internal` are both required.
- `body` is trimmed, then must be 1–2000 characters; the trimmed value is persisted.
- `internal` accepts only a JSON boolean.
- `author` is the token `sub`; `createdAt` is server-generated.
- Success is 201 with `id`, `author`, `body`, `internal`, and `createdAt`.
- Existing validation, error, serialization, and unknown-field conventions remain unchanged.
