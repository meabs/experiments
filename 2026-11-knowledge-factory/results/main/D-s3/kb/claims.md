Map the partner outcome to an action: approved -> issue with the returned credit_limit; declined -> decline with limit 0; manual_review -> queue_review with limit 0 (do not decline). In API v2, outcome "manual_review" replaces v1 "refer" and is handled exactly as spec section 3 prescribes. (source: changelog)

- [k5] The network referral rule applies only to self_employed applicants (not to all partners/applicants); an employed applicant is not forced into review by requested_limit. (source: spec)
- [k6] The referral threshold is strictly "above 4000" (requested_limit > 4000); a self_employed applicant with requested_limit exactly 4000 is not forced into manual review by the network rule. (source: spec)
