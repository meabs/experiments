- [k1] svc.apply(app) submits a Calloway application and returns a dict. Application fields: id, age, income, employment (employed or self_employed), requested_limit. (source: spec)
- [k2] Calloway is now on API v2 (current): svc.apply returns {"api_version": 2, "result": {"outcome": "approved"|"declined"|"manual_review", "credit_limit": <int>}}. The v1 fields `decision` and `limit` are removed. outcome manual_review replaces refer. (source: changelog)
- [k3] handle(app, svc) returns {action, limit} using the v2 response result.outcome/result.credit_limit. outcome approved -> action issue with credit_limit; declined -> action decline with limit 0; manual_review -> action queue_review with limit 0 (manual_review is not a decline; it goes to the manual review queue, handled as per spec section 3). (source: changelog)
- [k4] Network referral rule: for every partner in the network, an application from a self_employed applicant whose requested_limit is above 4000 must be placed in manual review (queue_review) instead of being issued — it overrides an approval. A decline stays a decline. (source: spec)
